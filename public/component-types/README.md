# Icônes des types de composants

Déposez ici une icône PNG transparente pour chaque type. Le nom du fichier doit correspondre exactement à la clé ci-dessous. Les icônes peuvent être carrées (conseillé : 256 × 256 px).

```text
tyre.png
wheel.png
fork.png
chainrings.png
cassette.png
chain.png
pedals.png
brake-rotor.png
brake-pads.png
shock.png
seat-post.png
bottom-bracket.png
brake.png
cranks.png
battery.png
chainguide.png
hub.png
inner-tube.png
sprocket.png
stem.png
handlebar.png
sealant.png
other.png
```

Une même icône est utilisée pour toutes les fiches de son type. Si un PNG manque, son emplacement reste vide jusqu’à ce que le fichier soit ajouté.
